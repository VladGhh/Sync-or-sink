# 🧩 Synk or Sink

## 📖 Descrierea Proiectului
Synk or Sink este un joc 2D de tip local co-op, conceput pentru a readuce la viață nostalgia vremurilor în care împărțeam același calculator cu un prieten pentru ore întregi de distracție. 

Jocul este destinat exclusiv a doi jucători care controlează două personaje 2D și trebuie să lucreze strâns împreună pentru a avansa în nivel. Intenția din spatele mecanicii de split-screen este asemănătoare cu cea din titluri precum A Way Out sau It Takes Two, oferind fiecărui jucător propriul fir de acțiune. Cu toate acestea, succesul este complet interdependent: în stilul clasicelor jocuri Fireboy & Watergirl, jucătorii trebuie să rezolve puzzle-uri complexe care necesită coordonare, comunicare și înțelegere reciprocă.
